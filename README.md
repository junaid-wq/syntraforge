# SyntraForge FrameGrab 📸

> **Live Web Application:** [https://syntraforge.me](https://syntraforge.me)

Instant, lossless 4K video frame extraction utility running entirely in your browser.

## Features
- **Zero Cloud Uploads:** Extraction executes locally via HTML5 Canvas and WebGL APIs inside system RAM.
- **Sub-Frame Stepping:** Navigate video timelines frame-by-frame with 1/30s granularity.
- **Native Pixel Accuracy:** Exports match true native media dimensions (4K UHD, 1080p, or vertical 9:16).
- **Multiple Formats:** Supports Lossless PNG, high-quality JPEG, and WebP.
